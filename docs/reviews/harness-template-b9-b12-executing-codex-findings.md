### Adjudication

- **MAJOR 1 (is_instance_surface patterns too broad) — ACCEPT + FIX.** This is the PARAMOUNT
  over-broad-exemption concern. The `startswith("docs/") and endswith(...)` patterns exempt NESTED paths
  (`docs/core/foo-context.md`, `docs/archive/bar-state.md`) — a future nested core doc would be silently
  exempted. The implementer pattern matches non-markdown (`implementer-helper.py`). FIX: restrict the
  docs/ patterns to a SINGLE path segment (`docs/<name>.md`, no further slash) and the implementer cells
  to `.md` only. Add distinguishing tests for the nested-path and non-md cases.

- **MAJOR 2 (manifest cross-check doesn't force registration of a forgotten core doc) — ACCEPT + FIX.**
  Real future-safety gap: a new `docs/comms-context.md` forgotten in BOTH the manifest and CORE_DOC_RELPATHS

  only iterates SHIPPED_MANIFEST). FIX (chosen): add the production-path regression Codex asks for — drive

  skipped, i.e. the partition must FLAG an UNMANIFESTED docs/*.md that matches a core-doc-shaped suffix

  neither in SHIPPED_MANIFEST nor an instance file SHOULD be caught. Realize by tightening `_unaccounted`:
  an instance-suffix docs/ file that is NOT in SHIPPED_MANIFEST and NOT under an instance prefix is treated
  as UNACCOUNTED (it must be either manifested-as-core or a real instance file under docs/briefs or an
  instance stub). This makes the manifest gate fail-closed for a forgotten shipped core doc. (A genuine
  germinated instance doc like docs/rd-context.md is NOT tracked in the template's manifest gate run — the
  template tree has none — so this does not break the bare-clone tree.)

- **MINOR 1 (_inbox_for_role references REGISTERED_ROLE) — ACCEPT + FIX.** Cheap robustness for the
  never-block invariant. Guard the helper: use `_registered_role` and gate the per_generation_inbox call on
  _REGISTRY_IMPORT_OK.

- **MINOR 2 (mixed-state misses full stub sentence) — ACCEPT + FIX.** A filled doc that retained the FULL
  stub sentence is wrongly accepted (is_stub True short-circuits). FIX: in the dual-state helper, when the
  full stub sentence is present BUT the doc also carries real filled content beyond the stub structure,
  treat it as the mixed/half-edit state. Pragmatic discriminator: a stub is SHORT and carries only
  placeholder fill markers; a doc carrying the stub sentence AND substantial extra content is the half-edit.
  Add the bad full-sentence simulated payload as a regression.

Disposition: NOT converged. Fixing M1, M2, m1, m2 then re-running.
